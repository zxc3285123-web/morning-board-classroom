# 아침 열기 칠판

[웹사이트 열기](https://zxc3285123-web.github.io/morning-board-classroom/)

날짜, 요일, 날씨, 출석, 기분, 일과, 급식을 차례로 확인하는 교실용 화면입니다. 선생님 화면에서 학교를 등록하면 날짜에 맞는 급식을 자동으로 불러옵니다.

## 사용하기

1. 위 웹사이트 주소를 엽니다.
2. 오른쪽 위 **선생님**을 누릅니다.
3. **학교 찾기**에서 학교를 고르고 **저장하고 닫기**를 누릅니다.
4. **공유**를 누르면 학교 정보가 담긴 링크를 복사할 수 있습니다.

학생 이름과 활동 기록은 사용하는 기기의 브라우저에만 저장됩니다. 급식 정보는 별도 서버를 거쳐 나이스 학교급식 API에서 가져옵니다. 인증키는 이 저장소에 포함되지 않습니다.
